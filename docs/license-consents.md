## 登记规则

1. 核对回复账号与历史 PR/提交的关系；作者名、邮箱或提交署名只能
   提供线索，身份有疑问时请本人说明对应的提交/PR。
2. 保存贡献者明确确认的项目、适用许可（Apache-2.0/MIT）、历史贡献范围、授权
   权限及例外。仅有“支持”“同意”或表情时，请补充明确范围的回复。
3. 对 Issue 评论记录永久链接、评论 ID 和日期，并备份原文；如有
   编辑，应核对最终文字。不要只有维护者填写的勾选状态。
4. 通过 PR 确认时，保留贡献者本人提交/评论的明确授权文字，以及
   PR 和提交链接；只修改一个状态单元格的 PR 需要补充说明。
5. 邮件或其他私下记录保留原件与上下文；公开表只登记经同意公开的
   摘要或引用，避免公开私人联系方式与敏感材料。
6. 有雇主或其他权利主体时核对授权权限。范围不完整、未回复或身份
   未对应时，继续保留待确认状态。

原始记录和表格应一同保留。此登记流程帮助保存可复核的授权证据，
不把 GitHub 账号、勾选框或某一种通信渠道视为自动的权利证明。
